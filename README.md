Summary:

Multi-agent system for legal compliance research over bulk US case law from Case.Law. A proof-finding agent searches the corpus for supporting excerpts, a risk-scoring agent rates exposure and sentiment, and an orchestrator agent assembles an answer with citations back to the source documents.
